# Founder Content Site

A simple static landing page for a founder-led content service.

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `styles.css` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the live Pages URL.

## Before publishing

Replace:
- `hello@example.com` in `index.html` with the real email.
- Any copy you want to personalize for your actual offer.
